# ECO-Link: Circular E-Waste Management & Material Recovery Platform

ECO-Link connects verified recyclers, informal collectors, and e-waste generators through a transparent, rule-based digital marketplace featuring CPCB/EPR compliance verification, scrap price reference checks, and digital material lot traceability.

## Core Operational Workflow
1. **Recycler Demand**: CPCB/EPR verified recyclers post e-waste requirements (Category, Quantity, Target Price).
2. **Collector Response**: Informal collectors browse demands, declare available items, and submit asking prices.
3. **Rule-Based Price Check**: ECO-Link validates asking prices against deterministic reference scrap ranges, triggering interactive price warnings if above market limits.
4. **Recycler Match & Lot Creation**: Recyclers compare matching collectors and select a partner to generate a traceable **Digital Material Lot** (`LOT EL26-TN-XXXXX`).
5. **QR-Based Handover**: Physical material transfer is verified via QR code scan and status updates through to formal certified recycling.

## User Roles
- **E-Waste Generator**: Request doorstep e-waste disposal, track material lot journeys, and view green receipts.
- **Informal Collector**: Browse recycler demands, declare materials, calculate reference lot values, and confirm QR handovers.
- **Verified Recycler**: Post requirements, compare rule-matched collectors, process intake material, and issue certificates.
- **Admin**: Monitor platform health, manage reference scrap price datasets, and review CPCB audits.
